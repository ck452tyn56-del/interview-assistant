# Fast Assistant (v27) — переработка v26

Только Google Gemini Live API. Одна модель, один ответ, минимальная задержка.

## Что удалено из v26

| Удалено | Зачем |
|---|---|
| Вторая модель («Gemma», gemini-2.5-flash) и её панели | Лишний раунд к API (~1-3с), ответ и так есть |
| Loopback системного звука + микшер | Шум системы дёргал VAD и задерживал ответы; пользователь говорит в микрофон |
| Interview Mode | Не используется |
| Health Monitor | Заменён простым авто-переподключением |

## Что ускорило реакцию

1. **Push-to-Talk (режим по умолчанию, `MODE = "ptt"`)**:
   - Держишь **ПРОБЕЛ** — ассистент слушает. Распознавание идёт **в реальном времени**
     (промежуточный текст виден в «Слышу» уже во время речи).
   - Отпустил **ПРОБЕЛ** — отправляется сигнал `activityEnd`, и генерация ответа
     начинается **мгновенно**. Нет ожидания паузы 500–800мс, как в авто-VAD.
   - Паузы внутри вопроса допустимы: сервер не начнёт отвечать на полу-вопросе.
2. **Модели с авто-fallback** (первая доступная подключается сама):
   `gemini-3.8-live` → `gemini-3.1-flash-live-preview` (thinking=minimal) →
   старая `gemini-2.5-flash-native-audio-preview-12-2025` из v26.
3. **MODE = "auto"** (если нужен hands-free): VAD ускорен — пауза конца речи
   800мс → **500мс**, чувствительность начала/конца речи **HIGH**, padding 500→200мс.
   **F9** — форсировать ответ немедленно, не дожидаясь паузы.
4. **Компактный system prompt** — жёстко: максимум 2–3 предложения, сразу суть.
5. Индикатор **⚡ X.Xs** — реальное время от отпускания пробела до первого слова
   ответа (в auto — от конца речи до первого слова).

## Установка

```powershell
pip install pyaudiowpatch sounddevice google-genai numpy pynput
```

Ключ: создать рядом `assistant_secrets.py`:

```python
API_KEY_GEMINI = "твой_ключ"
```

(или переменная окружения `GEMINI_API_KEY`; файл уже в .gitignore)

## Запуск

```powershell
python fast_assistant.py
```

1. Нажать **CONNECT**.
2. Ждать статуса «ГОТОВ — держи ПРОБЕЛ» (или LISTENING в auto).
3. Держать пробел, говорить вопрос, отпустить — ответ появится в панели.

Ответы чередуются между двумя панелями: прошлый ответ не перекрывается новым.

## Тонкая настройка (верх файла `fast_assistant.py`)

| Константа | Что делает |
|---|---|
| `MODE` | `"ptt"` (пробел=говорить) / `"auto"` (слушает всегда) |
| `SILENCE_MS` | Пауза тишины до ответа в auto-режиме (500). Меньше = быстрее, но можно резать речь |
| `PREFIX_PADDING_MS` | Захват начала речи в auto-режиме (200). Меньше = можно срезать первое слово |
| `MODEL_CANDIDATES` | Список моделей с fallback; поменяй порядок при желании |
| `MAX_FONT` / `MIN_FONT` | Пределы автоподгонки шрифта ответа |

## Если микрофон не открывается

Код сам пробует: pyaudiowpatch → pyaudio → sounddevice (WDM-KS — на машине
автора v26 работал именно fallback). Проверить в Windows: микрофон включён,
доступ у приложений разрешён. Лог: `fast_assistant.log` (строки `[AUDIO]`).

## Рекомендации по микрофону

Говорить в 15–30см от микрофона — при такой дистанции индикатор 🎤 Vol держится
40–70%, распознавание уверенное и пауза ловится быстрее.
