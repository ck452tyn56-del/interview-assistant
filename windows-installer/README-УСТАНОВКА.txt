Fast Assistant — голосовой IT-ассистент (Windows 10/11)
======================================================

УСТАНОВКА
---------
1. Двойной клик: Install-FastAssistant.bat (права администратора не нужны)
2. Ждать «Готово!». На рабочем столе появится ярлык «Fast Assistant».
3. Запуск: двойной клик по ярлыку.

Приложение: %LOCALAPPDATA%\Programs\FastAssistant
Данные (ключ, настройки, лог): %APPDATA%\FastAssistant

ВАЖНО ПРО АРХИВ
---------------
Рядом с установщиком лежит assistant_secrets.py с твоим API-ключом —
установщик скопирует его автоматически. НИКОМУ не передавай этот архив целиком!

КАК ПОЛЬЗОВАТЬСЯ
----------------
• Пробел зажать = говорить (окно в фокусе, либо галка «Пробел в любом окне»
  для конференций).
• Отпустил пробел = ответ за 1-2 секунды (⚡ показывает время реакции).
• Источник: Микрофон / Система (системный звук — для Zoom/Meet).
• Reset = новый диалог (уточнения между репликами работают и так).
• Прокси: галка + адрес (по умолчанию socks5://127.0.0.1:8081 — SSH-туннель).

УДАЛЕНИЕ
--------
%LOCALAPPDATA%\Programs\FastAssistant\uninstall.bat
(ключ и настройки сохранятся в %APPDATA%\FastAssistant)
